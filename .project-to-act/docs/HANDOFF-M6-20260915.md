- **问题**：门对象实测只有 7 个键，**无任何金额**——审批人被要求批准一句"成本确认是生效写"，看不到总额、单价、账期、订单号，也看不到 `cost_incomplete`。而 D-005 立三段式的理由正是"财务不可接受生效事实先落库"，`_apply_m6_close_month` 还特意"审阅什么就冻结什么"。形式上有门，实质是盲批。

- **关键撞车点**：`tests/test_migration_m0.py:446` 精确断言"不传诊断字段时 gate 键集 == 7 个"。若写成无条件 `review={}`，该测试立刻变红。
